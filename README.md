# Mestermunka_2026-27
Mestermunka repository 

Gyimesi Ádám, Kálosi István és Scherer Márk mestermunka repója. 

Az étteremrendszerező webalkalmazás célja az éttermek mindennapi működésének egyszerűsítése és átláthatóbbá tétele. Segítségével egy helyen kezelhetők az étlapon szereplő ételek, a rendelések, az asztalfoglalások, valamint a vendégekkel és az alkalmazottakkal kapcsolatos információk. A rendszer megkönnyíti a munkafolyamatok szervezését, csökkenti az adminisztrációt, és segíti a hatékonyabb működést.
